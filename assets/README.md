# Federanorth imagery

`federanorth-aerial.png` is the original hero asset generated with the built-in imagegen tool for this project. It is embedded into the standalone dashboard, so the page also works offline. The roads are decorative imagery, not a map of a submission's actual location. Orange grid lines and route overlays are implemented in HTML/CSS/SVG.

Final generation prompt:

> Use case: photorealistic-natural. Asset type: website hero background photograph for Federanorth, a commercial-property underwriting app. Generate one photorealistic straight-down aerial drone photograph of an elegant multi-road highway interchange crossing deep green woodland with small geometric agricultural plots near the edges, late afternoon sunlight grazing the tree canopy. Gray-blue asphalt roads, tiny lane markings, realistic road engineering, looping ramps and a long diagonal overpass create a striking architectural composition. Premium editorial photography, rich dark forest greens and olive highlights, strong shadow detail, subtle organic grain. Landscape 3:2 composition, edge-to-edge landscape. No text, logos, UI, borders, orange markings, graphics, or watermarks. The photograph will be displayed in a large right-hand hero panel and must look like an actual aerial photograph, not an illustration.
